```text
fix(economia): evitar el doble gasto de monedas

Las compras leian el saldo, restaban y guardaban sin bloqueo: 16 compras
simultaneas de dos macetas entregaban las dos pagando una (5 de 5 intentos).

- UsuarioRepository.bloquear: SELECT ... FOR UPDATE al empezar toda operacion
  que mueve monedas o XP (tienda, abono, revivir y premios de ProgresoService).
- V27: CHECK monedas >= 0 como ultima defensa.
- ManejadorErrores: una restriccion de la BD (duplicado, saldo negativo) es 409,
  no 500.
```
