## Mensaje del commit

```text
fix(seguridad): aceptar solo imagenes reales en la subida de fotos

StorageService usaba la extension del nombre que manda el cliente y no
revisaba el contenido: se podia subir un .html o .svg con JavaScript y
servirlo desde /files/ (mismo origen que la web) para robar la sesion.
Ahora la extension sale de los magic bytes (JPG, PNG, WEBP); lo demas da 415.
Se agrega delete() para limpiar fotos de escaneos fallidos.
Tests: StorageServiceTest.
```
