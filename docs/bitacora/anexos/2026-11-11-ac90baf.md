## Mensaje del commit

```text
fix(seguridad): el panel admin de Django exige token de sesion

Antes bastaba con enviar X-Admin-Id con el id del admin para editar el
catalogo y lanzar eventos. Ahora el login genera un token (usuarios.session_token)
y cada escritura exige X-Admin-Id + X-Admin-Token, comparado en tiempo constante.
El login ya no revela si un correo existe o si no es admin (mismo 401).
```
